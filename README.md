# Terraform
Day 01 – Introduction to Terraform

1. What is Terraform?

Terraform is an open-source Infrastructure as Code (IaC) tool developed by HashiCorp.

It allows us to provision, manage, and modify infrastructure using configuration files instead of manually creating resources through cloud provider consoles.

Terraform uses HCL (HashiCorp Configuration Language) to define infrastructure.

It supports multiple providers, including:

AWS

Microsoft Azure

Google Cloud Platform

Kubernetes

2. Basic Terraform Workflow

Terraform follows these important steps:

Write: Create Terraform configuration files.

Initialize: Download required providers and initialize the working directory.

Plan: Preview infrastructure changes.

Apply: Create or modify infrastructure.

Destroy: Remove Terraform-managed infrastructure when required.
